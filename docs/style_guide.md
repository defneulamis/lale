# Lale Turkish Game Localization Style Guide

## Purpose

This guide defines principles for creating natural, consistent
and high-quality Turkish game localization.

## General Principles

- Prefer natural Turkish over word-for-word translation.
- Keep terminology consistent throughout a game.
- Consider the context in which a term appears.
- Preserve the tone and personality of the original text.
- Avoid unnecessary English terminology when a natural Turkish equivalent exists.

## Terminology

Preferred terminology should be recorded in the Lale glossary.

When multiple Turkish translations are possible, context should determine
which translation is appropriate.

## UI Text

UI translations should be:

- concise
- clear
- natural
- appropriate for limited screen space

## Dialogue

Dialogue should preserve:

- character personality
- tone
- emotional meaning
- cultural context

Literal translation should not be prioritized over natural dialogue.
